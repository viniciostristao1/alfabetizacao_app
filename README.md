# Primeiras Palavras

App Flutter para uma criança **aprender a ler**: escolhe um tema (Animais, Objetos, Alimentos,
Nomes) e um nível por sílabas (Fácil/Média/Difícil), e lê palavras grandes numa tela em paisagem.
Tema escuro. Offline. MVP só com texto (áudio, figura, microfone e gamificação vêm depois).

**Comece por [`INICIO.md`](INICIO.md)** · regras em [`AGENTS.md`](AGENTS.md) · padrões em
[`ARQUITETURA.md`](ARQUITETURA.md) · futuro em [`IDEIAS.md`](IDEIAS.md).

## Rodar / verificar
```bash
cd app
/root/flutter/bin/flutter pub get
/root/flutter/bin/flutter analyze lib/ test/
/root/flutter/bin/flutter test
```
